Política de Privacidade

Motor de Conteúdo — Manual do Recém-Nascido · Última atualização: 22 de setembro de 2026

Esta Política descreve como o Motor de Conteúdo do Manual do Recém-Nascido (conteudo.manualdorecemnascido.com.br) trata dados ao integrar-se com as APIs oficiais do TikTok, Instagram, Facebook e YouTube.

1. Quem somos

Ferramenta interna operada por Manual do Recém-Nascido para publicar conteúdo próprio da marca nas suas próprias contas oficiais de redes sociais. Não coletamos dados de terceiros nem de seguidores.

2. Dados que tratamos

  • Tokens de acesso das contas de rede social conectadas pelo próprio dono da conta, usados apenas para publicar o conteúdo que ele carregou. São armazenados de forma restrita e usados só para esse fim.
  • Informação básica do perfil conectado (nome de usuário e id da conta), para identificar em qual conta o conteúdo será publicado.
  • Mídia e legendas que o próprio usuário carrega para publicar.

3. Como usamos

Os dados são usados exclusivamente para autenticar a conta e publicar o conteúdo preparado pelo usuário nas plataformas conectadas. Não vendemos, alugamos nem compartilhamos esses dados com terceiros.

4. Uso da API do TikTok

Ao usar a Content Posting API do TikTok, tratamos apenas o token de acesso e a informação básica do perfil autorizados pelo usuário. O uso segue os Termos de Serviço e as políticas do TikTok for Developers. O usuário pode revogar o acesso a qualquer momento nas configurações do TikTok (Apps e sites).

5. Retenção e exclusão

Tokens são mantidos apenas enquanto a integração estiver ativa. Ao revogar o acesso, o token deixa de ser usado. Solicitações de exclusão: contato@brunotropolis.com.br.

6. Segurança

Os tokens são armazenados de forma restrita e transmitidos por conexões seguras (HTTPS).
